# Python Fundamentals Practice

A collection of 80+ hands-on practice programs I wrote while learning the
fundamentals of Python. Files are named `ChX_PSY.py`, meaning Chapter X,
Problem Set Y, so the repo follows the course order.

## What's covered

| Chapter | Topics |
|---------|--------|
| 2 | Variables, operators, type(), user input |
| 3 | Strings: f-strings, replace, find, escape sequences |
| 4 | Lists and tuples: append, sort, sum, count, immutability |
| 5 | Dictionaries and sets: lookups, update, hashing, uniqueness |
| 6 | Conditionals: if/elif/else, logical operators, `in` checks |
| 7 | Loops: for/while, prime check, factorial, star patterns |
| 8 | Functions: return values, recursion, unit conversion |
| 9 | File I/O: read/write/append, copy and compare files, text filtering |
| 10 | OOP: classes, `__init__`, class vs instance attributes, static methods |
| 11 | Inheritance, `@property`, operator overloading |
| 12 | Exception handling, `enumerate`, list comprehensions |
| 13 | `str.format`, `join`, `filter`, `reduce` |

## Highlights
- High-score game with file persistence
- Complex number and 3D vector classes with operator overloading
- Train booking class demonstrating OOP basics
- Recursion examples (sum of n numbers, pattern printing)
- Spam-comment detector and simple profanity censor
